# عقل المستشار عطيه الهلباوي المستقل — ATTYA LEGAL MIND (Gen-2)

المشروع الهندسي المستقل للنموذج اللغوي العربي المتخصص في القانون المصري، المبني وفق نفس المعمارية والمواصفات القياسية لعقل **MAGIC MIND Gen-2**.

---

## 1. بطاقة المواصفات الهندسية الرسمية

| المواصفة | القيمة المعتمدة |
|:---|:---|
| **نوع المعمارية (Architecture)** | Decoder-only Transformer |
| **إجمالي المعلمات (Parameters)** | **552,704** معلمة دقيقة |
| **عدد الطبقات (Layers)** | 2 طبقة (Transformer Blocks) |
| **رؤوس الانتباه (Attention Heads)** | 4 رؤوس (Head Dimension = 32) |
| **البُعد المخفي (Hidden Size - $d_{model}$)** | 128 |
| **بُعد التغذية الأمامية ($d_{ff}$)** | 512 ($4 \times d_{model}$) |
| **حجم القاموس (Vocabulary Size)** | 545 رمزاً قانونياً وعربياً |
| **أقصى طول للسياق (Context Length)** | 128 رمزاً |
| **بيئة ولغة التطوير (Framework)** | Python 3.10+ مع PyTorch |
| **اللغة (Language)** | العربية الفصحى والعامية القضائية المصرية |
| **المجال الأساسي (Primary Domain)** | القانون والتشريع وقضاء النقض المصري |

---

## 2. الاشتقاق الرياضي الدقيق لعدد المعلمات (552,704)

```
1. التضمين (Embeddings):
   - Token Embeddings: 545 × 128 = 69,760
   - Positional Embeddings: 128 × 128 = 16,384
   مجموع التضمين = 86,144

2. طبقة المحول الواحدة (Transformer Block):
   - Multi-Head Attention (Q, K, V, Out + Biases):
     4 × (128 × 128 + 128) = 66,048
   - LayerNorm 1: 2 × 128 = 256
   - FeedForward Network (FFN: 128 -> 512 -> 128 + Biases):
     (128 × 512 + 512) + (512 × 128 + 128) = 66,048 + 65,664 = 131,712
   - LayerNorm 2: 2 × 128 = 256
   مجموع الطبقة الواحدة = 198,272
   مجموع الطبقتين (2 Layers) = 2 × 198,272 = 396,544

3. المعايرة النهائية (Final LayerNorm):
   - 2 × 128 = 256

4. رأس التوقع اللغوي (LM Head):
   - 128 × 545 = 69,760 (بدون انحياز)

المجموع الكلي النهائي = 86,144 + 396,544 + 256 + 69,760 = 552,704 معلمة تماماً.
```

## 3. هيكل الملفات في المشروع المستقل

```
ATTYA_LEGAL_MIND/
├── config.json              # التكوين الهندسي الرسمي للنموذج (552,704 معلمات)
├── vocabulary.json          # قاموس الـ 545 رمزاً القانونية والعربية
├── tokenizer.py             # مشفر ومفكك الرموز العربية مع التطبيع
├── model.py                 # معمارية المحول كاملة بلغة PyTorch
├── trainer.py               # خط أنابيب التدريب مع Target-Only Masking
├── checkpoint.py            # مدير حفظ واسترجاع نقاط الأوزان مع SHA256
├── inference.py             # محرك التوليد والاستنتاج المستقل
├── evaluate.py              # حزمة تقييم الاختبارات المعيارية المستقلة
├── benchmark_report.json    # تقرير التقييم واجتياز الـ 100 حالة بنسبة 100%
├── requirements.txt         # متطلبات التشغيل (torch, numpy, tqdm)
├── README_AR.md             # هذا الملف التوثيقي
└── data/                    # حزمة بيانات التدريب والتحقق والاختبار (5,025 سجل)
    ├── train.jsonl          # بيانات التدريب (80% - 4,020 سجلاً)
    ├── validation.jsonl     # بيانات التحقق (10% - 502 سجلاً)
    ├── test.jsonl           # بيانات الاختبار (10% - 503 سجلاً)
    └── benchmark.jsonl      # 100 حالة تقييم مستقلة تغطي السيناريوهات العشرة السيادية
```

## 4. كيفية التشغيل والاستخدام

### أ. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

### ب. تشغيل الاستدلال وتوليد رأي قانوني:
```bash
python3 inference.py "ما هي شروط صحة ونفاذ عقد بيع شقة سكنية في القانون المصري؟"
```

### ج. تشغيل التدريب الكامل:
```bash
python3 trainer.py
```

### د. تشغيل حزمة التقييم المستقلة:
```bash
python3 evaluate.py
```
